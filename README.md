# PocketNode Monorepo

Autonomous Android Media & Torrent Server ecosystem. Turn any spare Android device into an autonomous self-hosted node running embedded Jellyfin, Jackett Torznab, BitTorrent engine, and Telegram remote downloads.

## 📂 Repository Structure

- **[`remote-movie-pc-downloader/`](./remote-movie-pc-downloader/)**: PocketNode Core (Server daemon, embedded Jellyfin HTTP server, libtorrent BitTorrent engine, Jackett Torznab, Telegram bot controller).
- **[`pocketnode-client/`](./pocketnode-client/)**: PocketNode Client (Android TV, tablet, and mobile client built with Jetpack Compose & ExoPlayer).
- **[`pocketnode-website/`](./pocketnode-website/)**: Public landing page and APK distribution portal.
