The Complete PocketNode Ecosystem

A high-performance dual-app architecture tailored for zero friction.

THE HOST DAEMON

PocketNode Core (Server)

Runs as a persistent foreground Android service on your server phone with lock-screen wake-locks.

  • Embedded Jellyfin Media Server with REST API
  • Native Libtorrent4j C++ engine (DHT + Magnet)
  • Jackett multi-indexer aggregator on port 9117
  • Telegram Bot for remote one-click downloads
  • Zero-config Wi-Fi mDNS broadcast

THE CONTROLLER & PLAYER

PocketNode Client

Install on your daily phone, tablet, or Android TV to discover and stream from your PocketNode daemon.

  • Instant mDNS zero-setup discovery on Wi-Fi
  • Direct media stream with hardware decoding
  • Remote transfer queue management & stats
  • Clean modern tactical HUD UI
  • Background push notifications for completed media

How To Set Up In 3 Minutes

No port-forwarding, no Linux CLI knowledge, no dynamic DNS headaches required.

01

Install Server APK

Install PocketNode Core on any spare Android phone connected to your Wi-Fi, grant storage permissions, and tap START DAEMON.

02

Zero-Config Discovery

Open PocketNode Client on your main device. It automatically detects pocketnode.local on the network with no manual IP entry needed.

03

Stream & Download

Send magnet links directly from Telegram, search torrents via Jackett, or play high-bitrate video straight to your Smart TV or phone.
