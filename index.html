How To Set Up In 3 Minutes

No port-forwarding, no Linux CLI knowledge, no dynamic DNS headaches required.

01

Install Server APK

Install PocketNode Core on any spare Android phone connected to your Wi-Fi, grant storage permissions, and tap START DAEMON.

02

Zero-Config Discovery

Open PocketNode Client on your main device. It automatically detects pocketnode.local on the network with no manual IP entry needed.

03

Stream & Download

Send magnet links directly from Telegram, search torrents via Jackett, or play high-bitrate video straight to your Smart TV or phone.
